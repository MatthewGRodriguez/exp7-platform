# ADR 0008: JFactor is first class
Status: decided (2026-10-30)
Decision (Matthew: "it's a J project so we need JFactor as a first class"): JFactor scoring is in scope from the first version, not deferred. The JFactor item is the base unit of the level format; views (calendar, cash criticality, plan) are JFactor views. Exp7 may be developed inside this project later.
Reference: docs/legacy-reference/jfactor/api (JBlueprint, JGroup, JAction, Joy, scoring), exp6 docs. See docs/design/06.
