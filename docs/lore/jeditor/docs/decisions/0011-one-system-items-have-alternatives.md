# ADR 0011: One system; items have alternatives
Status: decided (2026-10-30)
Decision (Matthew: "each item will have alternatives, same system just the view of the different paths"): a level has ONE JFactor system. Each item holds its own alternatives. The Plan view (JPlan) is only a view of the different paths through those alternatives, including the current path. There are no separate alternate plan systems as different models.
Supersedes the "alternate system / alternate plan systems" wording in ADR 0009. See docs/design/06.
