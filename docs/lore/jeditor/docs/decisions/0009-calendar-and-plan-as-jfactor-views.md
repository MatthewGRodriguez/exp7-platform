# ADR 0009: Calendar, cash criticality and plan are JFactor views
Status: decided (2026-10-30)
Decision: (1) The ranking_ui Calendar tab becomes one component that combines several ranking_ui features, including the board items; these are JFactor first class. (2) [Superseded by ADR 0012: cash criticality is merged into the calendar as conditions-based highlighting, not a separate view.] (3) A generalized Plan view standardizes viewing different paths and the current path. Clarified by ADR 0011: one system; items hold alternatives; the Plan view shows paths through them (no separate alternate plan systems).
See docs/design/06.
