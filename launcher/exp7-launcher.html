About

Use a fine-grained key for your own personal data repo. A key with wider access (for example one that can create that repo) also works; the platform never writes the software repo. The key stays in this tab's memory and is never stored or reported. The platform is downloaded from the software repo MatthewGRodriguez/exp7-platform (read-only, no key sent), pinned to a commit, checked against its SHA-256, and kept for offline use.
